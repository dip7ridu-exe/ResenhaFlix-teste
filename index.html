APIs, URLs e arquivos JSON

Faixas completas: o ResenhaFlix usa Audius quando possível. A iTunes continua como catálogo complementar e prévia. A chave de API do Audius é gratuita e pode ser usada no frontend.
SoundCloud: para pesquisar dentro do ResenhaFlix sem expor seu Client Secret, configure o Worker incluído no ZIP. Sem Worker, links diretos do SoundCloud ainda podem ser tocados pelo player oficial e a busca externa continua disponível.
A busca geral usa Open Library. Livros gratuitos usam Gutendex/Project Gutenberg. Downloads só aparecem para itens marcados como domínio público ou explicitamente liberados.
